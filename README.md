# Cool Cursor for Chrome

made by Danya and Yaroslav

## Как установить

1. На этой странице нажать `<> Code` -> Download ZIP
2. Распаковать архив в удобное место
3. В Google Chrome нажать три точки справа наверху
4. Выбрать [Extensions](chrome://extensions/)
5. Справа наверху включить Developer mode
6. Слева тыкнуть Load unpacked -> выбрать эту папку
